online purchase integration guide

this page explains how to connect your e‑commerce “thank you” page to perkminer so that member purchases are recorded and cashback can be paid correctly.

important: this script must be installed on your order confirmation / “thank you” page and kept in place at all times while online purchases are enabled in your perkminer business dashboard.

1. how the flow works

  1. a perkminer member clicks “shop on this business's website” and is redirected to your site with a perk_token in the url.
  2. after the customer completes payment, your order confirmation (“thank you”) page loads.
  3. on that page, a small script:
    • reads perk_token from the page url
    • reads the final order total from your platform
    • calls https://www.perkminer.com/api/record_external_sale
  4. if the call succeeds, the customer is redirected back to perkminer to view their cashback receipt.

2. script to add to your order confirmation page

add the following script to your order confirmation / “thank you” page. your developer will need to replace the line that sets orderTotal with your platform’s real order total value. 

<script>
(function() {
  // 1) get perk_token from the URL
  function getPerkToken() {
    var params = new URLSearchParams(window.location.search || "");
    return params.get("perk_token");
  }

  var perkToken = getPerkToken();
  if (!perkToken) {
    // Not a PerkMiner session, nothing to do
    return;
  }

  // 2) get the final order total from the platform
  // TODO: REPLACE this with your platform's actual order total variable.
  // Examples:
  //   - Shopify: use Shopify.checkout.total_price / 100
  //   - Custom: expose the total into window.PERK_ORDER_TOTAL before this script
  var orderTotal = window.PERK_ORDER_TOTAL;  // <-- must be set to a number in USD

  if (typeof orderTotal !== "number" || orderTotal <= 0) {
    console.warn("PerkMiner: order total is missing or invalid.");
    return;
  }

  // 3) send the data to PerkMiner
  fetch("https://www.perkminer.com/api/record_external_sale", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
      perk_token: perkToken,
      amount: orderTotal
    })
  })
  .then(function(res) { return res.json(); })
  .then(function(data) {
    if (data && data.status === "ok" && data.summary && data.summary.transaction_id) {
      // 4) redirect the member to their PerkMiner receipt
      var tid = data.summary.transaction_id;
      var receiptUrl = "https://www.perkminer.com/user/receipt/" + encodeURIComponent(tid);
      window.location.href = receiptUrl;
    } else {
      console.error("PerkMiner: API error", data);
      // Optional: show a generic message if needed
    }
  })
  .catch(function(err) {
    console.error("PerkMiner: failed to report external sale", err);
    // Optional: show a generic message if needed
  });
})();
</script>

tip the orderTotal value must be the final amount paid by the customer (in us dollars), including item prices and any discounts, but before perkminer’s advertising fee.

3. how to provide the order total

shopify (example)

on the order status page, shopify often exposes a Shopify.checkout object. your developer can set: 

<script>
  // total_price is in cents
  window.PERK_ORDER_TOTAL = Shopify.checkout.total_price / 100.0;
</script>

this snippet should appear before the main perkminer script.

custom / other platforms

for a custom website or other platforms, your developer just needs to expose the final order total into window.PERK_ORDER_TOTAL before the perkminer script runs. for example: 

<script>
  // Replace 123.45 with your real order total variable
  window.PERK_ORDER_TOTAL = 123.45;
</script>

4. important terms and compliance

  • you must maintain an advertising account balance of at least $250 while online purchases are enabled in your perkminer business dashboard.
  • if your balance falls below $250, perkminer will automatically block new online purchases until you add more funds.
  • you are required to keep the perkminer tracking script installed and active on your order confirmation / “thank you” page while online purchases are enabled.
  • removing, disabling, or altering the script so that purchases are not reported may result in suspension of your account. repeated or intentional violations may result in permanent account closure and forfeiture of any remaining advertising balance, as stated in your perkminer terms.
  • if a member reports that they completed a purchase on your website but did not receive cash back, perkminer may suspend your account while we investigate and will review whether the script was installed and working correctly.
for questions or help with installation, please contact support@perkminer.com.
