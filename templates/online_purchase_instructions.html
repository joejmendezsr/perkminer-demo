Online Purchase Integration Guide

This page explains how to connect your online store to PerkMiner so member purchases are recorded and cash back is paid correctly.

Sale amounts are verified. A purchase only counts when the amount is sent by your store's server (or by Shopify) and signed with your private Sales Key. The amount can never come from the shopper's browser, which protects you from inflated sales and unexpected advertising fees.

1. How the flow works

  1. A PerkMiner member clicks “Shop on this business's website” and lands on your site with a perk_token in the URL.
  2. Script A (every page) saves that token for 24 hours.
  3. When the customer places an order, your server keeps the token with the order. When the order is paid, your server tells PerkMiner the order number and total, signed with your Sales Key (WooCommerce and custom sites), or Shopify does it for you with its signed “Order payment” webhook.
  4. PerkMiner records the sale once (re-sending the same order is safe), pays cash back, and bills your 10% advertising fee.
  5. Optional: Script B on your order confirmation page sends the customer to their PerkMiner receipt.

2 Script A — add to every page of your site (inside <head>)

Saves the token so it is still available at checkout. Required for every platform.

3 Report the paid order from your server

Choose the one that matches your store. The order number and total must come from your own database / order object, never from the browser.

A) WooCommerce (WordPress)

1) Add these two lines to wp-config.php (above the “That's all, stop editing” line):

{% filter forceescape %}{% raw %}define('PERKMINER_BUSINESS_ID', 'YOUR_BUSINESS_ID');
define('PERKMINER_SALES_KEY',  'YOUR_SALES_KEY');{% endraw %}{% endfilter %}

2) Add this to your theme's functions.php (or a code-snippets plugin):

{% filter forceescape %}{% raw %}// Sends a signed request to PerkMiner
function perkminer_post($path, $payload) {
  $body = wp_json_encode($payload);
  $ts   = (string) time();
  $sig  = hash_hmac('sha256', $ts . '.' . $body, PERKMINER_SALES_KEY);
  return wp_remote_post('https://www.perkminer.com' . $path, array(
    'timeout' => 15,
    'headers' => array(
      'Content-Type'          => 'application/json',
      'X-PerkMiner-Business'  => PERKMINER_BUSINESS_ID,
      'X-PerkMiner-Timestamp' => $ts,
      'X-PerkMiner-Signature' => $sig,
    ),
    'body' => $body,
  ));
}

// 1) at checkout: keep the member's token with the order
add_action('woocommerce_checkout_create_order', function ($order) {
  if (!empty($_COOKIE['perk_token'])) {
    $order->update_meta_data('_perk_token', sanitize_text_field(wp_unslash($_COOKIE['perk_token'])));
  }
});

// 2) when the order is paid: report the REAL total from the order
function perkminer_report_order($order_id) {
  $order = wc_get_order($order_id);
  if (!$order || $order->get_meta('_perk_reported')) return;
  $token = $order->get_meta('_perk_token');
  if (!$token || $order->get_currency() !== 'USD') return;   // not a PerkMiner customer / not US dollars
  $res = perkminer_post('/api/external_sale/confirm', array(
    'perk_token' => $token,
    'order_id'   => (string) $order->get_id(),
    'amount'     => round((float) $order->get_total(), 2),
  ));
  if (!is_wp_error($res) && in_array(wp_remote_retrieve_response_code($res), array(200, 409), true)) {
    $order->update_meta_data('_perk_reported', '1');
    $order->save();
  }
}
add_action('woocommerce_order_status_processing', 'perkminer_report_order');
add_action('woocommerce_order_status_completed',  'perkminer_report_order');

// 3) connection test: while logged in as an admin, open  https://YOURSITE.com/?perkminer_test=1
add_action('init', function () {
  if (isset($_GET['perkminer_test']) && current_user_can('manage_woocommerce')) {
    $r = perkminer_post('/api/ecommerce/verify-beacon', array('ping' => true));
    wp_die('PerkMiner replied: ' . esc_html(is_wp_error($r) ? $r->get_error_message() : wp_remote_retrieve_body($r)));
  }
});{% endraw %}{% endfilter %}

B) Custom website — PHP

Save $_COOKIE['perk_token'] in your orders table when the order is created, then call this when the order is paid:

{% filter forceescape %}{% raw %}function perkminer_report_sale($perkToken, $orderId, $total) {
  $body = json_encode(array('perk_token' => $perkToken, 'order_id' => (string)$orderId, 'amount' => round((float)$total, 2)));
  $ts   = (string) time();
  $sig  = hash_hmac('sha256', $ts . '.' . $body, 'YOUR_SALES_KEY');
  $ch = curl_init('https://www.perkminer.com/api/external_sale/confirm');
  curl_setopt_array($ch, array(
    CURLOPT_POST => true, CURLOPT_POSTFIELDS => $body, CURLOPT_RETURNTRANSFER => true, CURLOPT_TIMEOUT => 15,
    CURLOPT_HTTPHEADER => array('Content-Type: application/json',
      'X-PerkMiner-Business: YOUR_BUSINESS_ID', 'X-PerkMiner-Timestamp: ' . $ts, 'X-PerkMiner-Signature: ' . $sig),
  ));
  $response = curl_exec($ch);
  $status   = curl_getinfo($ch, CURLINFO_HTTP_CODE);
  curl_close($ch);
  return array($status, $response);   // 200 = recorded (or already recorded). 402 = add funds, then retry.
}{% endraw %}{% endfilter %}

C) Custom website — Node.js (18 or newer)

{% filter forceescape %}{% raw %}const crypto = require("crypto");

async function perkminerReportSale(perkToken, orderId, total) {
  const body = JSON.stringify({ perk_token: perkToken, order_id: String(orderId), amount: Math.round(Number(total) * 100) / 100 });
  const ts = String(Math.floor(Date.now() / 1000));
  const sig = crypto.createHmac("sha256", process.env.PERKMINER_SALES_KEY).update(ts + "." + body).digest("hex");
  const res = await fetch("https://www.perkminer.com/api/external_sale/confirm", {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      "X-PerkMiner-Business": process.env.PERKMINER_BUSINESS_ID,
      "X-PerkMiner-Timestamp": ts,
      "X-PerkMiner-Signature": sig
    },
    body
  });
  return { status: res.status, body: await res.json() };   // 200 = recorded (or already recorded). 402 = add funds, then retry.
}{% endraw %}{% endfilter %}

4 Script B (optional) — send customers to their PerkMiner receipt

Add to your order confirmation (“thank you”) page on custom sites and WooCommerce. It sends no amount; it only waits until PerkMiner has recorded the sale (usually a few seconds) and then opens the member's receipt. Not available on Shopify, where members see their cash back in their PerkMiner account.

5 Test your connection

PerkMiner's team confirms your store by seeing a signed test ping from it. Send one after installing:

  • WooCommerce: while logged in as admin, open https://YOURSITE.com/?perkminer_test=1. It should say "ok":true.
  • Shopify: press Send test notification next to your webhook.
  • Any server with a command line (replace the two placeholders):
{% filter forceescape %}{% raw %}KEY="YOUR_SALES_KEY"; BIZ="YOUR_BUSINESS_ID"
TS=$(date +%s); BODY='{"ping":true}'
SIG=$(printf '%s.%s' "$TS" "$BODY" | openssl dgst -sha256 -hmac "$KEY" | awk '{print $NF}')
curl -s -X POST https://www.perkminer.com/api/ecommerce/verify-beacon \
  -H "Content-Type: application/json" -H "X-PerkMiner-Business: $BIZ" \
  -H "X-PerkMiner-Timestamp: $TS" -H "X-PerkMiner-Signature: $SIG" -d "$BODY"{% endraw %}{% endfilter %}

Replies: {"ok":true} = connected. bad signature = wrong Sales Key or the body was changed after signing. timestamp too old = your server clock is off by more than 5 minutes.

What the server replies

  • 200 – sale recorded (or this order was already recorded – sending it twice is safe).
  • 402 insufficient_balance – add funds to your PerkMiner advertising balance, then send the order again.
  • 409 – that member session already has a recorded sale.
  • 400 / 401 – something is wrong with the request, token or signature (the reply says what).

Important terms and compliance

  • You must maintain an advertising account balance of at least $250 while online purchases are enabled in your PerkMiner business dashboard.
  • If your balance falls below $250, PerkMiner will automatically block new online purchases until you add more funds.
  • You are required to keep the PerkMiner integration installed and active while online purchases are enabled, and to report the true amount paid by the customer.
  • Removing, disabling, or altering the integration so that purchases are not reported, or reporting incorrect amounts, may result in suspension of your account. Repeated or intentional violations may result in permanent account closure and forfeiture of any remaining advertising balance, as stated in your PerkMiner terms.
  • If a member reports that they completed a purchase on your website but did not receive cash back, PerkMiner may suspend your account while we investigate and will review whether the integration was installed and working correctly.
